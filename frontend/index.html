01

Masukkan data Excel

File dikirim ke server penjadwalan milikmu (bukan ke pihak lain) dan disimpan di riwayat supaya hasilnya bisa dibuka lagi nanti.

XLSX / XLSM

Belum ada file yang dipilih.

02

Atur penjadwalan

Patokan kapasitas (pekerja per bulan, unit mesin, kalender) dibaca dari Excel. Kalau ada perubahan jumlah pekerja atau mesin, isi di bawah.

PYTHON

Patokan akan tampil setelah Excel dibaca.

Jumlah pekerja yang diisi berlaku sama untuk semua bulan (menggantikan patokan per bulan di Excel). Nama mesin harus sama persis dengan sheet Resources. Perubahan jumlah shift belum didukung karena kalender di kode penjadwalan terkunci 400 menit produktif per hari.

Setelah Excel terbaca, tombol penjadwalan akan aktif.
03

Riwayat penjadwalan

Setiap hasil tersimpan di server. Buka kembali kapan saja, atau unduh Excel input yang dulu dipakai.

TERSIMPAN
